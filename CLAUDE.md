# Vipulasena Pathirajage: personal blog

Bilingual (English / Sinhala) blog for **Vipulasena Pathirajage** (BSc, PGDE, MA),
former Director of Science Education, Ministry of Education, Sri Lanka.
It has a public website and an admin area for adding and managing content.

It began as a single working HTML file built on claude.ai. That prototype is kept
in `reference/prototype.html`. The site is now a **Next.js** app on **Vercel**,
with **Neon Postgres**, **Auth.js** (username and password) and **Vercel Blob**.
The design and behaviour are deliberately unchanged from the prototype.

See `README.md` for how to set it up and run it.

## Stack decisions

| Choice | Why |
|---|---|
| Next.js App Router, real routes | `/education`, `/media/recent` and so on. The prototype used hash routing with no SEO and no shareable links. |
| Server rendering, per request | Language comes from a cookie and content from the database, so there is nothing to prerender. `cacheComponents` is off for that reason. |
| Auth.js, username and password | Accounts live in `site_admins` with a scrypt hash. There is no sign-up form: accounts are made with `npm run admin:add`. Google sign-in was tried first and dropped at the user's request on 2026-11-22. |
| Vercel Blob | Photos and PDFs. One package, no separate account. |
| Folders, Education only | One level deep. An article may sit in a folder or straight in its section, so nothing has to be filed. The `folders` table allows any section; `SECTIONS_WITH_FOLDERS` in `lib/types.ts` decides which offer them in the admin. |
| Cookies for language and theme | The server renders the right language and theme on the first paint — no flash, no text swapping after load. |

## Design system (keep exactly)

The stylesheet is `app/globals.css`, carried over from the prototype unchanged
apart from a short section at the end.

**Colours (light)** are CSS variables on `:root`:

| Token | Value | Use |
|---|---|---|
| `--paper` | `#FAF8F3` | Warm Ivory, page background |
| `--surface` | `#F0ECE4` | Soft Cream, cards and panels |
| `--ink` | `#292824` | Charcoal, headings and primary text |
| `--body` | `#3B3934` | Paragraph text |
| `--muted` | `#6E695F` | Small labels. The client's Warm Gray `#827D73`, one shade deeper to pass 4.5:1 contrast |
| `--accent` | `#7E5F42` | Links and buttons. The client's Muted Brown `#9B7653`, one shade deeper for contrast |
| `--gold` | `#9B7653` | Muted Brown for decorative lines, rings and drawings |
| `--line` | `#E6E0D6` | Light Beige borders |
| `--deep` | `#3B342C` | Dark cocoa: Education feature card and Education thumbnails |

Dark mode redefines the same tokens (warm browns) under
`@media (prefers-color-scheme: dark)` and `:root[data-theme="dark"]`.

**Type:** Lora for headings, Jost for body text. In Sinhala mode,
`:root[lang="si"]` switches to Noto Serif Sinhala / Noto Sans Sinhala with
taller line heights.

**Each topic page has its own feel on a shared layout:**
- Education: graph-paper header, turning atom, flask with rising bubbles, molecule, "H₂O"; deep cocoa thumbnails.
- General thoughts: ruled-paper header with a red margin line, italic title, journal with a quill that writes, quotation mark, bar chart; sharper card corners.
- Children's books: pastel colour patches (`--k1` to `--k4`), moon, twinkling stars, drifting clouds, paper plane, books with a sprout; rounded cards that tilt on hover.
- Media: photo-print dot texture, camera, film strip, swaying instant photos; albums drawn as stacked prints.

**Motion:** home load sequence (portrait reveal, staggered text, gold rule),
orbit rings, fixed background ribbons that drift. Everything respects
`prefers-reduced-motion`.

**Accessibility:** text contrast ≥ 4.5:1, visible focus rings, skip link, real
buttons and links, keyboard-operable lightbox and admin side panel, `aria-live`
status messages.

## Files carried over from the prototype

`lib/i18n-si.json` is generated by `scripts/extract-i18n.mjs` from the
prototype's `SI` dictionaries, so the already-drafted Sinhala is never retyped.
**Do not edit it by hand** — change the script and re-run it.

`app/home-content.tsx` and `components/art/*.tsx` were generated once, by
`scripts/build-home.mjs` and `scripts/html-to-jsx.mjs`, so the hand-drawn SVG
came across byte-for-byte. They are **ordinary source files now**: edit them
directly. `build-home.mjs` refuses to overwrite an existing home-content.tsx
unless given `--force`, and is kept only for diffing against the prototype.

## Database

`database/neon-schema.sql` creates `articles`, `albums`, `photos`, `questions`,
`visits` (plus the `visit_totals` view) and `site_admins`.
`database/002-sender-hash.sql` adds the column the question form's rate limit uses.
`database/003-admin-login.sql` adds the username, password hash and the
`admin_login_attempts` table the sign-in lockout uses.
`database/004-general-thoughts.sql` renames the `academic` section to `general`,
after "Academic posts" became "General thoughts" on 2026-11-22.
`database/005-folders.sql` adds the `folders` table and `articles.folder_id`.
`npm run db:migrate` runs all four.

`database/006-clear-samples.sql` empties articles, albums and photos. It was run
on 2026-11-22 when the sample content was no longer wanted; admin accounts,
questions and visits are left alone.

Public reads only return `published = true` articles. Every admin action calls
`requireAdmin()` before touching anything, and `currentAdmin()` re-checks the
account against the database on every request, so removing an account takes
effect at once rather than when the cookie expires. `DATABASE_URL` is a server
secret and never reaches browser code.

Passwords are hashed with Node's built-in scrypt (`lib/password.ts`): a random
salt each, compared with `timingSafeEqual`, and the same work done even when no
such account exists so the response time cannot reveal which usernames are real.
Ten wrong passwords in 15 minutes locks an account for the rest of that window.
